# 可直接导入 EvalPilot 的合成演示数据

文件：evalpilot-simulated-v1.csv。上传时模型版本填写 simulated-v1。UTF-8 BOM 编码，共 55 个有效事件、165 个字段，5 个异常输入用例不混入本文件。

30 个事件的预测与建议参考完全相同，25 个事件各注入一项差异：5 个漏姓名、5 个漏公司、5 个漏部分实体、5 个多识别人物，以及简称、地点粒度、错误姓名、错误公司和 OCR 噪声各 1 个。简称等属于严格写法差异，并非预先断言语义一定错误。

事件来自独立编写的虚构候选。predicted_* 是人为模拟的机器输出，不是真实模型调用；reference_* 是 AI 建议参考，未经用户独立审核，不是人工金标准。该文件用于验证导入、统计、Bad Case 和复核流程，不可作为真实模型效果或 RAG 提升证据。

实体列保存 JSON 数组，[] 明确表示没有实体。地点规则为原文所有明确提及地点，而非仅事件发生地；公司简称等规范遵循 datasets/public_candidates_v1/README.md。simulation_scenario 仅记录造错方式，程序不得将它当评审结论；当前评审仅使用描述、实体与政策。

可不勾选外部 LLM 直接运行。规则无法判断的 5 个字段预期进入复核，不能把它们预填为 AI 判定。
