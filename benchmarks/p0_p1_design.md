# P0/P1 实验设计：明确分类标准是否改善差异诊断

P0 是重建的简化基线，不是已找回的历史生产 Prompt。P1 在 P0 上仅追加分类定义及判断规则。两组保持标签名称、JSON Schema、安全约束、实体覆盖要求、原文引用要求、模型参数及程序门禁一致。

运行：

    .venv\Scripts\python.exe scripts/run_prompt_ab.py --design definitions --live

不加 --live 仅检查流程。生产仍使用 A，历史 A/B 及其输出不覆盖。

主要候选评分：原始输出主标签集合与候选答案的符合情况（分母包括全部案例）；自动接受项的标签符合情况；自动接受数量、耗时、Token。实体关联与证据正确性尚待独立核验，不应把标签正确当成诊断全部正确。只对双侧差异调用 LLM，不把规则已解决案例混入 Prompt 效果。

用户逐例修改意见：
- BENCH-05：不符合。
- BENCH-06：用户提出部分符合；与先前显式简称可接受的规则存在业务口径差异，字段等级暂不用于本实验评分。两组共享门禁仍沿用原有语义规则，故门禁后覆盖率须与原始标签结果一起解释。
- BENCH-09：用户提出不符合；原输入仍标记参考待确认，不能悄悄把参考未知改为空。此例不参与当前双侧差异试跑。

逐例人工标准尚未全部确认。当前为已见开发样本的小规模探索试跑，不能宣称准确率提升，也不能当独立留出实验。下一步冻结实体关联和证据预期、补充新案例，再重复实验。
