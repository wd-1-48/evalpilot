两份报告保留用户导出的原始内容，未编辑指标、诊断或任务 ID。版本标签来自导入时的命名，不代表不同抽取模型；两次预测与参考答案相同。

## 如何重放

按主 README 启动服务，上传 XLSX，版本填写 `city-calls-sim-v2`。文件中的 `model_version` 与导入值必须相同。先不启用外部评审运行，再使用同一数据集新建启用 LLM 的运行，比较报告与待复核队列。

相同代码和标注口径下，可复核严格计数：姓名 TP/FN/FP 为 166/39/65，公司为 121/24/13，地点为 138/52/37；事件全对 60/200。LLM 返回内容、延迟及通过校验数量可能变化，不能承诺重现 45 个通过、9 个待复核。耗时取自单次运行，不保证重放时一致。

## 数据来源与口径

数据从零编写，覆盖 40 种居民诉求，每种 5 条，包括欠薪、物业、噪音、供暖、消费退款、出行与公共设施。姓名、公司、城市和具体场所为虚构示例，不对应真实投诉；未复制原始信访业务记录。

`predicted_*` 是人为构造的机器识别结果；`reference_*` 是 AI 编写的建议答案，未经独立人工审核。样本含 60 条正确对照、五类错误各 25 条，以及 15 条遗漏加多识别的混合错误。180 条出现地点、160 条出现人名、135 条出现公司，其中 105 条同时包含三类实体。

- 人名只收明确姓名；被告、原告、居民、司机、工作人员等称谓不算人名。
- 公司收具名商业企业，保留分支机构的完整名称；企业名称里的地域字样不另算地点。
- 地点收原文明示的地名、连续完整地址与具名场所，连续地址取最长范围，不重复列出其市、区等子串；交通起终点均保留。
- 按事件去重，不猜测缺失实体。`[]` 表示对应类别无实体。
- `simulation_scenario`、`simulation_note` 仅说明预设造错方式，不是模型评审结论，不应作为独立评审的答案提示。

## 结果解释与溯源

两份报告来自用户提供的关闭／开启外部语义评审运行，保持导出原文不变：

- test-v1：任务 `b9fcdaa139bf4757a517cb2455c7e8d3`，外部 LLM 关闭，请求 0 次，规则结论 546，待复核 54，人工确认 0。
- test-v1.2：任务 `b7759383983d43c79f650216dafa7bb1`，外部 LLM 启用，请求 54 次，规则结论 546，LLM 自动通过校验 45，待复核 9，人工确认 0。

`(54 - 9) / 54 = 83.3%` 表示待复核字段数量的减少，不是 600 个字段减少到 9 个，也不是实测人工工时节省。自动校验通过不能写成人工验证正确。

累计耗时为 8.96 秒和 309.17 秒，后者约为前者的 34.5 倍；字段 P95 分别为 17.26 和 15123.58 毫秒。这是单次运行观测，不能外推为固定延迟代价。严格指标相同是因为输入预测、参考答案及统计口径相同，语义诊断不修改严格计数。
